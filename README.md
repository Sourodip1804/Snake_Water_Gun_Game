# Snake Water Gun Game 🐍💧🔫

A simple command-line Python game based on the classic "Snake, Water, Gun" concept (similar to Rock-Paper-Scissors), where the user plays against the computer.

## 🔹 Features

* Random choice generation for the computer using `random` module
* User input handling with short codes (`s`, `w`, `g`)
* Clear display of both user and computer choices
* Game logic to determine win, lose, or draw
* Simple and interactive console-based gameplay

## 🔹 Game Rules

* Snake 🐍 drinks Water 💧 → Snake wins
* Water 💧 douses Gun 🔫 → Water wins
* Gun 🔫 kills Snake 🐍 → Gun wins

## 🔹 How It Works

The user selects an option (`s`, `w`, or `g`), and the computer randomly picks one. The program then compares both choices and displays the result based on predefined rules.

## 🔹 Tech Stack

* Python

## 🔹 Learning Outcomes

* Conditional statements and decision-making
* Dictionaries for mapping inputs and outputs
* Random number generation
* Building simple game logic
